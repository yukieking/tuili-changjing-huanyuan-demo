# 场景与记录说明

三部作品共享场景、原文事件时间轴和个人推理工具。章节仅作依据索引。

## 当时所见

保留《十角馆事件》《无人生还》《如首无作祟之物》的原文观察、约时、遗体搬运和物证变化；误认和证词仍按当时的叙事呈现。没有明确位置时不延续上次位置。暗室随原文发现显示。完整解答、真实身份映射和补述作案行动已移除。

原文中的尺寸、建筑关系不完整；绝对尺寸、材质、棋子落点及服饰为示意，不用于证明行动耗时或机关。记录采用原创短摘要与章次索引，不包含原书全文或插图。

## 自己推理

每本书独立保存多份方案。位置点、停留区间、遗体位置假设、证词和随记分开记录；证词不自动成为棋子位置。可从当前所见复制人物位置作为自己的起点；小说记录不会被修改。物证及已知场景保留在切换前的原文节点。

位置重叠及证词差异只提示疑点，不自动判定凶手或真假。方案保存在当前浏览器，可导出备份和导入；删除操作可撤销。时间以方案内“第几日 + 钟点”表示，不强制把跨年旧案转成真实经过时长。

## 三维查看

保留暖色、简洁建筑与Q版人物，开放旋转、平移及缩放。默认视角仍为原有立体角度；地图／房间切换时自动适配，同一地图的事件切换保留当前观察角度。房间聚焦隐藏遮挡的墙体或屋顶。平面图保留用于快速看清关系。

### 首无的建筑图鉴风格

首无采用与另外两本相同的浅暖色材质、正交视角和 Q 版人物尺度。村庄保留三条参道的方位，建筑群隐藏远山；聚焦婚舍时隐藏连接走廊和前墙，保留后墙与纸窗木格。荣螺塔是两条连续木板斜道，板缝仅表示铺板，不表示阶梯。

壁龛、壁橱、榻榻米、纸窗、格子门、祭坛、茶器清洗设施和手水舍来自已有文本空间记录。门把手、抽屉分格、茶具外形、檐部及清洗设施的具体位置为生活化示意，不能作为推理证据；未说明的宅邸内部仍不补造房间。平面图用地点编号和独立图例替代重叠文字，同处多人合并为人数标记，名字保留在悬停说明和人物列表中。
