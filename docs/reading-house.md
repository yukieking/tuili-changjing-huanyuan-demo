# 无人生还 · 阅读地图对照版

入口：`/reading.html`。原版入口、作品场景、推演与存储不变。对照版仅复用 Three.js 和人物模型，使用独立的浏览器存储键 `mijing-reading-house-v1`，不调用原版假说保存接口。

## 阅读方式

默认从第2章的入住空间开始；设置已读章节后，新增可见空间。建筑采用固定正交视角，可以缩放；分层显示用于理解上下关系，不表示真实层高。点击楼层查看该层；平面图点击房间进入房间立体图。人物默认没有位置，读者自行摆放 Q 版棋子、写随记、增加位置快照。依次查看快照时，平面图跟随同一人物切换楼层；不是路线或耗时验证。

## 依据与不确定性

以用户提供的中文 EPUB 章节顺序核对空间描写，以下均为概括，不收录正文或电子书。

| 空间 | 依据 | 模型限制 |
| --- | --- | --- |
| 大厅、客房层、维拉房间和浴室 | 第2章：台阶、平台、大厅；楼上走廊末端的客房；海景与东向窗；相邻浴室 | 建筑轮廓、比例、走廊方向与门位是示意 |
| 休息厅与邻室 | 第3章：壁炉旁的门连接邻室；邻室的留声机 | 只确认邻接，外形、尺寸、朝向与家具坐标为推定 |
| 餐厅 | 第3章：餐桌等室内物件 | 与大厅、厨房之间的平面关系不能据此确定 |
| 厨房、佣人房上层 | 第8章的空间描写与搜查段落：小楼梯、佣人房 | 用独立上层避免误画成客房；楼梯踏步数、层高不确定 |
| 其他客房 | 入住与后续客房描写确认有多个房间 | 合并为虚线未定区域，不擅自给出完整客房排列 |
| 阁楼与地窖 | 第12章确认存在 | 不足以定位，说明中列出，暂不建模 |

当前图是有依据的阅读辅助草图，不是精确建筑复原。圆窗、外部港湾等整体描述尚未完整建模；没有隐藏空间或结局演示。已读章节是场景信息提示，不是严格无剧透保证；人物名单仍来自全书主要角色。后续增加作品时，先整理空间事实、邻接关系、章节与推定，再人工校核，不能仅凭自动检索认定布局。

## 验证

前端领域测试验证空白记录、阅读进度隔离、错误存储恢复、人物位置持久化边界。浏览器人工检查建筑/楼层、2D 点击进入房间、随记、棋子与保存后重载。
