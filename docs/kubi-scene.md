# 《如首无作祟之物》场景模型说明（无结局剧透）

本作品新增在 `kubi.html`，保留《无人生还》功能 Demo，入口在作品档案。

## 小说结构与推演范围

故事围绕秘守一族、一守继承人与媛首山仪式展开。十三夜参礼与十年后的婚舍集会是不同事件，不能把两次仪式的行动混在同一时间线。叙述包含回忆、目击、调查整理与作者编排；人物称呼、穿着和目击身影也不能直接当成独立确认的身份。此版按登场介绍展示人物，不载入身份反转与结局。

当前参考用户提供的中文译本（张舟译），阅读核对了书前人物表与四幅地图、有关仪式和调查的章节，以及后部解析与尾声对前述记录的解释。产品的公开空间模型采用概述与重新生成的几何，未收录电子书正文、封面或原图。

## 空间关系

- 媛首山是村中央、东西向延伸的丘陵。北、东、南分别有入口鸟居、石阶、曲折参道与内侧小鸟居。
- 一守家面对北入口、二守家面对东入口、三守家面对南入口。媛守神社是东北小山上的另一处场所，与媛神堂不同。
- 北路净身地点为水井；东、南是手水舍。北路石碑与藏身树、东路马头观音祠分别建模。
- 境内铺玉砂利，媛神堂北侧为格子门，西侧走廊接荣螺塔。
- 塔为两条独立的木板螺旋斜道，在塔顶转接。神堂到婚舍和反向返回均须上塔再下塔。模型用橙色 A、青绿色 B 区分；不是普通楼梯，也不存在婚舍与神堂的地面捷径。
- 塔西侧从北到南为前、中、后婚舍。每舍具有四叠半茶室、茶器清洗间、六叠里间、壁龛及壁橱。里间两侧纸窗外有木格。
- 厕所在中婚舍背后，但书中要求折回媛神堂再从堂外绕行。连接图没有添加从中婚舍直出的门。

来源：书前《媛首村地图》《媛神堂·荣螺塔·婚舍示意图》《参道示意图》《荣螺塔构造图》；第一、三、五、十二、十七章。

## 明确事实与展示推定

**有文字/图示依据：** 方位、关键地点、连接顺序、双螺旋独立性、房间用途与榻榻米数量、部分门窗的相对关系。

**展示推定：** 绝对坐标、距离、塔高、旋转圈数、坡度、各建筑的轮廓尺寸、婚舍旋转角、外墙厚度、树木配置、材质、灯光与家具。双螺旋是关系模型，并非可用于建筑施工的精密结构。现阶段村域道路与地形作简化；宅邸只显示轮廓，没有复原其内部。平面图无比例尺。

**推理待核：** 监视的连续性、声音是否可听、目击可靠性、身份与通行耗时。玉砂利、格子窗与外围监视不被程序直接视作不可越过的物理屏障。

## 功能与存储

36 位人物支持按家族/角色筛选、按时刻在地点放置。用户选择起终地点和时段，连接图建议路线，点击确认后才加入假说；播放使用指定时段进行沿路线插值，不声称真实速度。可建立、复制、删除、命名、导出假说，按时刻添加解释。

默认阅读范围为人物/地图。选择“已读至第八章”后，仅展开第六章十三夜约时表中的部分调查记录。记录标明来源，不自动生成角色位置。目击中的第一次与第二次身影保持不同记录，不预先判定同一身份。

`GET/PUT /api/works/kubi/state` 与原 `/api/state` 分开；新文件为原存储文件同目录下的 `kubi-state.json`。浏览器使用 `mijing-kubi-v1`。切换已有行动的仪式时段会新建假说，保留原行动。JSON 的角色范围、时刻、地点、相邻连接与大小在 Java 中校验，并原子写入。

检查覆盖相邻连接、时间重叠、运动中的额外位置快照。还未实现观察视线遮挡求解、声音传播、自由路线编辑、门窗状态求解、完整案件复盘与身份假设系统。

## 验证

`node --test tests/frontend/*.test.mjs` 包含双螺旋分离、来回路径、塔内高度插值、厕所绕行、时段隔离与冲突检查。

`./mvnw test` 通过真实 HTTP 验证原作品与新作品互不覆盖、非法角色/路线拒绝、跨来源写入拒绝、大小限制以及持久化。
